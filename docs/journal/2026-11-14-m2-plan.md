# 2026-11-14 M2 plan

## 2026-11-14 decision: M2 plan of 20 tasks in two tracks, ADR-0005, 0006 and 0007 accepted

The M2 plan has 20 tasks in two tracks: benchmarks (hand-written calibrations of the four remaining cases, generality set storage) and pipeline (in-place repair, fix loops, convergence gate, Critic, Scorer after the Critic), followed by a live development series, a freeze and an acceptance series. The owner approved the plan and ADR-0005 (in-place repair behind `repair_mode`), ADR-0006 (fix loops and convergence gate, supersedes ADR-0004) and ADR-0007 (Critic and Scorer after the Critic) in chat. The gate thresholds in ADR-0006 are provisional until `cfd-reviewer` confirms them in Task 12.

## 2026-11-14 observation: code-reviewer found five blocking problems in the plan, fixed in round 2

Round 1 returned `changes` with five blocking findings: budget arithmetic and a missing rule-4 approval for the live series; route-back mechanics that conflicted with attempt-directory deletion and left stale outputs; a convergence gate that was infeasible as written (no periodic flag in the CaseSpec, a diagnosis turn that needed tools); task order; and the set of route targets. After the plan was changed, round 2 returned `approve`.

## 2026-11-14 decision: no `partial` run status; the Critic verdict is reported beside the status

Design 6.5 says a run hitting a limit ends `failed` or `partial`. The owner accepted the proposal that `status` stays the pipeline status and the Critic verdict (`success`, `partial`, `failed`) is a separate field, because that keeps M1 and M2 run records comparable and keeps the Critic's judgement apart from what the pipeline did, which the Critic-accuracy metric (design 9.2) needs. Recorded in ADR-0007.

## 2026-11-14 decision: M0-M2 envelope raised from $30 to $35

Cost Management showed about $9.3 spent of the $30 envelope, about $20.7 left, which also has to carry the fixed infrastructure cost of about $8.70 per month. The plan estimated $19-25.5 for the remaining M2 work, so the upper end exceeded the envelope. The owner raised the envelope to $35 and approved the caps of $7 for the Task 17 series and $6 for the Task 19 acceptance series; the sessions running them still announce in chat before spending.

## 2026-11-14 decision: each M2 task is implemented in a separate session on Sonnet

The owner chose to implement each task in its own session, on Sonnet, with the lean review workflow. The Azure cost of the planning session was zero.
