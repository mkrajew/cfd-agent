## 2026-11-06 experiment: wedge bounding box measured on real meshes (R29)

The dispatch asked to scale both radial bounds of the expected bbox by cos(a/2) for axisymmetric cases. Measured on a thin annulus (r 0.9 to 1.0, 10 degrees) in the image: the CAD box is y 0.896575 to 1, the mesh box y 0.896575 to 0.996195, so only ymax scales (ymin is already r cos(a/2) by the Planner convention); x and z match, and scaling both bounds fails. Both reviewers confirmed the implementer, not the dispatch wording. Consequence for benchmark thresholds: the one-cell wedge wall radius is short by R(1 - cos(a/2)), 0.095 % at 5 degrees and 0.38 % at 10 degrees (flow area twice that, mesh volume 0.5 % under CAD at 10 degrees).

## 2026-11-06 obstacle: reviews of Task 17 found a path escape and gates that passed unrunnable cases

The code reviewer found that `read_tutorial` could escape the tutorial directory through an absolute path containing `..` (Critical); fixed, together with a rule-order false positive in the constraint-type check. The CFD reviewer found that the trial run overwrote `startFrom`, `stopAt`, `endTime`, `writeControl` and `writeInterval` in its scratch copy while the consistency check did not inspect all of them, so a `controlDict` the solver cannot start (for example `writeControl timeStep` with `writeInterval 0.1`) passed both checks and died at the real start-up. The check now validates those keys. The same review found that profile end points taken from the ideal bounding box are silently dropped by OpenFOAM sampling on faceted boundaries (measured: 9 of 11 points returned when the end was 1 mm outside the mesh), and the prompt now says to take end points from the mesh.

## 2026-11-06 obstacle: solver summary showed the wrong residual (Task 18)

The CFD reviewer (Critical) found that the Solver Runner summary reported the linear solver's Final residual, which is bounded by the solver tolerance and says nothing about convergence, instead of the Initial residual that `residualControl` compares. Evidence: a diverged icoFoam run (Courant about 4e4) showed Final residuals of order 1e-8 while the true Initial residuals were 0.78, 0.70 and 0.99; a non-converged steady run showed 0.00196 against a true 0.0242. Fixed by keeping the Initial residual of the first and last solve per field and rewording summary and prompt. The same review required the failed-run diagnosis turn (which has no tools) to be preceded by log reading, a Courant-scaling recipe in the prompt, and wording that does not claim non-convergence when no `residualControl` is set; all fixed in one round.

## 2026-11-06 decision: Solver Runner rulings (Task 18)

A diagnosis is collected for every failed solver attempt, including the last, with one extra bounded model turn (R43). The stage does not retry after a failed solver run because the run is deterministic and the agent cannot change the case; it retries only when the solver was not run (R45, generic `retry_after_failure` hook, other stages unchanged). The solver timeout is the remaining wall clock minus the smaller of 600 s and 20 % of it (R46). Cost if wrong: a rerun with a different rank count after a parallel-only crash is lost (R45); a long run is cut up to 10 minutes early (R46); the loop needs rework when routing arrives in M2 (R43).

## 2026-11-06 decision: no convergence gate in M1 (R44), owner decision pending

The Solver Runner gate is only whether the last `run_solver` call succeeded; steady non-convergence is reported in the tool summary and handed to the Analyst, whose gate requires `analysis.md` to discuss convergence. This deviates from design 6.2 row 5, and both reviewers flagged it. Reason: the agent cannot edit the case and routing back to Case Setup is M2. Cost if wrong: an unconverged steady case reaches the Analyst. The owner has not yet decided; the choice of warning thresholds in the summary (Courant above 10, linear solver at 1000 iterations, more than 10 bounding messages) also awaits the owner and is a judgment value.

## 2026-11-06 experiment: OpenFOAM v2512 behaviours verified by the CFD reviewer

The reviewer checked in the image: `simpleFoam` stops early on `residualControl` ("SIMPLE solution converged in 6 iterations") and the log parser handles converged and non-converged runs; `pimpleFoam` never stops on `residualControl` (only the dictionary form applies), so only `simpleFoam` counts as steady in the summary; a deliberately divergent `icoFoam` case (time step 50) gave Courant numbers 0, 2329, 4278, 14358 and 39895 and a floating-point exception at step 5 of 100, deterministically; empty patches run with no entry, a wildcard entry or `patchType empty`, so the checker's explicit-entry requirement is a convention, not an OpenFOAM rule; sampling interior cross-sections works with `surfaceFieldValue` on a cutting plane, which is now in the prompt.
