## 2026-11-13 observation: branch protection does not require infra-lint and sandbox

Branch protection on main requires the status checks lint, unit, image and integration, plus pull request reviews, enforced for administrators. `infra-lint` and `sandbox` run in CI and gate `publish` through `needs`, but they are not required checks for merging, so a pull request can be merged while they fail. Item E of the M0 carry-over (infra-lint in the required checks) was therefore only partly done: done in `publish.needs`, not done in branch protection. The status table in `docs/design/m1-carryover-from-m0-review.md` said this was not re-checked; it was checked after the release and the table now says so. Whether to add the two checks is the owner's decision.
