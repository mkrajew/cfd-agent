## 2026-11-12 experiment: README quick-start check on the project VM

The check used a bare host at eae8031 with image `sha-eae8031` and nothing else set up. These commands worked as written: `cfdagent --help`; `cfdagent run` with no task and with `--benchmark` and an unknown id (both exit 2, the latter lists the five known benchmarks); `cfdagent run task.md --model gpt-oss-120b --reasoning-effort high --no-upload`; `cfdagent run --benchmark cavity-re100 --detach` followed by `cfdagent status`, `cfdagent logs --follow` and `cfdagent list`. `logs --follow` ran to the end of the run and printed `upload: done, 130 file(s)`. Exit 0 was not exercised in this check; the completed runs of the earlier series and the scripted replay of Task 22 returned it.

## 2026-11-12 obstacle: `--benchmark` depends on the working directory

`--benchmark` reads `benchmarks/` relative to the working directory, so the command only works from the host checkout (`/opt/cfdagent-src`). The README now says so.
